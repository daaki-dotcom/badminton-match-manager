# 機能一覧

## バドミントン試合管理ツール

**バージョン:** 2.0  
**作成日:** 2026-05-07

---

## 凡例

| 記号 | 意味 |
|------|------|
| ✅ | フェーズ1：実装済み |
| 🔲 | フェーズ2：開発予定 |

| 権限表記 | 意味 |
|---------|------|
| 全員 | 未ログイン・ゲスト含む全員 |
| 正規部員 | ログイン済みの正規部員 |
| 変更（全体） | 変更（全体）権限を持つ正規部員 |
| 管理者 | 登録権限を持つ正規部員 |
| システム | 自動処理 |

---

## 1. 出欠管理

| # | 機能名 | 概要 | 権限 | フェーズ |
|---|--------|------|------|---------|
| 1-1 | 正規部員 出欠登録 | リストから自分の名前を選んで参加・不参加・未定を回答する | 正規部員 | ✅ |
| 1-2 | ゲスト 出欠登録 | 名前を自由入力して「参加」のみ回答する | 全員 | ✅ |
| 1-3 | 参加者一覧表示 | 参加メンバーの一覧を表示・コピーする | 全員 | ✅ |
| 1-4 | 活動日設定 | 次回活動日（YYYY-MM-DD）を設定する | 変更（全体） | ✅ |
| 1-5 | 出欠リセット | 出欠データを全件クリアする | 変更（全体） | ✅ |
| 1-6 | ゲスト削除 | 当日参加できなくなったゲストを削除する | 変更（全体） | 🔲 |
| 1-7 | 自動リセット | 活動日から7日後にゲストの出欠データを自動クリアする | システム | ✅ |

## 2. メンバー管理

| # | 機能名 | 概要 | 権限 | フェーズ |
|---|--------|------|------|---------|
| 2-1 | 参加者一覧表示 | 「参加」と回答したメンバーを一覧表示する | 全員 | ✅ |

| 2-3 | レベル設定 | 各メンバーの経験者・未経験者をトグルで設定する | 変更（全体） | ✅ |
| 2-4 | 正規部員登録 | 新しい正規部員をシステムに登録する | 管理者 | 🔲 |
| 2-5 | 正規部員削除 | 正規部員をシステムから削除する | 管理者 | 🔲 |
| 2-6 | 権限付与 | 正規部員に変更（全体）・登録権限を付与する | 管理者 | 🔲 |
| 2-7 | アカウント管理画面 | 正規部員の一覧・権限を管理する画面 | 管理者 | 🔲 |

## 3. 試合管理（組み合わせタブ）

| # | 機能名 | 概要 | 権限 | フェーズ |
|---|--------|------|------|---------|
| 3-1 | 参加枠選択 | 全員・経験者のみ・未経験者のみから対象を選ぶ | 変更（全体） | ✅ |
| 3-2 | 試合形式選択 | シングルス / ダブルスを選択する | 変更（全体） | ✅ |
| 3-3 | 試合数指定（シングルス） | 1人あたり◯試合 / 合計試合数の上限 / 指定しない から選ぶ | 変更（全体） | ✅ |
| 3-4 | 試合数指定（ダブルス） | 合計試合数の上限 / 指定しない から選ぶ | 変更（全体） | ✅ |
| 3-5 | 均等にするトグル | 全員の試合数を均等にする（均等不可なら警告表示） | 変更（全体） | ✅ |
| 3-6 | 連続不可トグル | 直前ラウンドの出場者を次ラウンドに出場させない | 変更（全体） | ✅ |
| 3-7 | 連続不可の自動緩和 | 人数が少なく条件を満たせない場合に自動で連続不可を緩和する | システム | 🔲 |
| 3-8 | 組み合わせ生成 | フェーズ構造アルゴリズムで試合を生成する | 変更（全体） | ✅ |
| 3-9 | ルール設定の折りたたみ | 生成後にルール設定カードを自動折りたたみ・手動開閉できる | 全員 | ✅ |
| 3-10 | 試合ステータス管理 | 待機中・試合中・終了のステータスを管理する | 変更（全体） | ✅ |
| 3-11 | スコア入力 | 各試合の得点を入力する（最大2桁） | 変更（全体） | ✅ |
| 3-12 | 組み合わせリセット | 生成した試合をすべてクリアする | 変更（全体） | ✅ |

|---|--------|------|------|---------|

| 4-4 | レベルバッジ表示 | 経験者・未経験者バッジを順位表に表示する | 全員 | ✅ |
