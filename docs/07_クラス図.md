# クラス図（コンポーネント構成図）

## バドミントン試合管理ツール

**バージョン:** 2.0  
**作成日:** 2026-05-07

---

## 概要

React はクラスではなくコンポーネントと Hooks で構成されます。  
本ドキュメントでは従来のクラス図の代わりに **コンポーネント依存関係図・責務定義・Props/State 定義** を記述します。

---

## 1. コンポーネント依存関係図

```
main.tsx
└── App.tsx（ルートコンポーネント）
      │
      ├── hooks/useFirebase.ts       ← Firebase 接続・全状態管理
      │     └── firebase.ts          ← Firebase 初期化・設定
      │
      ├── types.ts                   ← 全型定義（全コンポーネントが参照）
      │
      ├── algorithm.ts               ← 試合生成アルゴリズム（Matches が参照）
      │
      ├── components/Header.tsx      ← ヘッダー・接続状態・タブナビ
      │
      ├── components/Attendance.tsx  ← 出欠タブ
      │
      ├── components/Members.tsx     ← メンバータブ
      │
      ├── components/Matches.tsx     ← 組み合わせタブ
      │     └── algorithm.ts
      │
      ├── components/Results.tsx     ← 結果・順位タブ
      │
      └── components/Party.tsx       ← 懇親会タブ
```

---

## 2. 各コンポーネント・モジュールの責務

### App.tsx（ルート）

| 項目 | 内容 |
|------|------|
| 責務 | アプリ全体の状態管理・タブ制御・全イベントハンドラ定義 |
| 内部 State | `activeTab: TabId` |
| 外部依存 | `useFirebase` フック |
| 子コンポーネント | Header / Attendance / Members / Matches / Results / Party |

**提供するハンドラ:**

| ハンドラ名 | 処理内容 |
|-----------|---------|
| `handleSubmitAttendance` | 出欠を登録・更新する |
| `handleRemoveAttendance` | 出欠レコードを削除する |
| `handleResetAttendance` | 全出欠データをリセットする |
| `handleSetActivityDate` | 活動日を設定する |
| `handleToggleLevel` | メンバーのレベルを切り替える |
| `handleUpdateCourts` | コート数を更新する |
| `handleGenerate` | 試合組み合わせを生成して保存する |
| `handleUpdateScore` | スコアを更新する |
| `handleUpdateStatus` | 試合ステータスを更新する |
| `handleSetParty` | 懇親会参加状況を登録する |
| `handleResetParty` | 懇親会データをリセットする |

---

### hooks/useFirebase.ts

| 項目 | 内容 |
|------|------|
| 責務 | Firebase Realtime Database とのリアルタイムデータ同期・自動リセット処理 |
| 副作用 | `onValue()` で全データをリアルタイム監視、`.info/connected` で接続状態監視 |

**提供する値:**

| 値 | 型 | 説明 |
|----|----|----|
| `state` | `AppState` | Firebase から同期した全アプリ状態 |
| `connected` | `boolean` | Firebase 接続状態 |
| `loading` | `boolean` | 初回データ取得中フラグ |
| `syncing` | `boolean` | 書き込み処理中フラグ |
| `fbSet` | `(path, value) => void` | Firebase にデータをセットする |
| `fbUpdate` | `(path, value) => void` | Firebase の特定フィールドを更新する |

---

| 項目 | 内容 |

| Prop | 型 | 説明 |

| `onRemove` | `(name) => void` | 出欠削除ハンドラ |
| `onReset` | `() => void` | 全リセットハンドラ |
| `onSetActivityDate` | `(date) => void` | 活動日設定ハンドラ |

---

### components/Members.tsx

| 項目 | 内容 |
|------|------|
| 責務 | 参加者一覧・レベルトグル・コート数設定 |

**Props:**

| Prop | 型 | 説明 |
|------|----|------|
| `attendance` | `Record<string, AttendanceStatus>` | 出欠データ |
| `memberLevels` | `Record<string, MemberLevel>` | レベルデータ |
| `courts` | `number` | コート数 |
| `onToggleLevel` | `(name) => void` | レベル切替ハンドラ |
| `onUpdateCourts` | `(n) => void` | コート数更新ハンドラ |

---

### components/Matches.tsx

| 項目 | 内容 |
|------|------|
| 責務 | 試合形式選択・条件設定・組み合わせ生成・スコア入力・ステータス変更 |
| 内部 State | `matchType`, `tierFilter`, `singlesMode`, `limitPer`, `limitTotal`, `ruleEqual`, `ruleConsec`, `isCollapsed` |
| 依存 | `algorithm.ts`（`generateSingles`, `generateDoubles`） |

**Props:**

| Prop | 型 | 説明 |
|------|----|------|
| `attendance` | `Record<string, AttendanceStatus>` | 出欠データ |
| `memberLevels` | `Record<string, MemberLevel>` | レベルデータ |
| `matches` | `Match[]` | 試合データ |
| `courts` | `number` | コート数 |
| `onGenerate` | `(matches: Match[]) => void` | 生成結果保存ハンドラ |
| `onUpdateScore` | `(index, s1, s2) => void` | スコア更新ハンドラ |
| `onUpdateStatus` | `(index, status) => void` | ステータス更新ハンドラ |

---

### components/Results.tsx

| 項目 | 内容 |
|------|------|
| 責務 | 終了試合から順位・勝敗・得点差を計算して表示する（閲覧専用） |

**Props:**

| Prop | 型 | 説明 |
|------|----|------|
| `matches` | `Match[]` | 試合データ |
| `memberLevels` | `Record<string, MemberLevel>` | レベルデータ（バッジ表示用） |

**順位計算ロジック:** 勝利+2pt・引き分け+1pt・敗北+0pt → ポイント → 勝利数 → 得点差 の優先順で順位決定

---

### components/Party.tsx

| 項目 | 内容 |
|------|------|
| 責務 | 懇親会参加回答・未回答者優先表示・全員回答後の集計 |

**Props:**

| Prop | 型 | 説明 |
|------|----|------|
| `attendance` | `Record<string, AttendanceStatus>` | 出欠データ（参加者の特定に使用） |
| `party` | `Record<string, PartyStatus>` | 懇親会データ |
| `onSetParty` | `(name, status) => void` | 参加状況登録ハンドラ |
| `onReset` | `() => void` | リセットハンドラ |

---

### algorithm.ts

| 項目 | 内容 |
|------|------|
| 責務 | 試合組み合わせ生成ロジック（UI から完全分離） |

**公開関数:**

| 関数名 | 引数 | 戻り値 | 説明 |
|--------|------|--------|------|
| `generateSingles(opts)` | `GenerateOptions` | `Match[]` | シングルス試合を生成する |
| `generateDoubles(opts)` | `GenerateOptions` | `Match[]` | ダブルス試合を生成する |

**内部関数:**

| 関数名 | 説明 |
|--------|------|
| `shuffle(array)` | Fisher-Yates シャッフル |
| `buildSinglesRounds(pool, courts, prevRound, ruleConsec)` | ラウンド単位の対戦リスト生成 |
| `shouldRelaxConsec(pool, courts, prevRound)` | 連続不可を緩和すべきか判定（フェーズ2） |

## 3. 型定義一覧（types.ts）

```
AttendanceStatus ─── 'yes' | 'no' | 'undecided' | ''
MemberLevel ─────── 'exp' | 'nov'
MatchStatus ─────── 'wait' | 'playing' | 'done'
MatchType ───────── 'singles' | 'doubles'
TierFilter ──────── 'all' | 'exp' | 'nov'
PartyStatus ─────── 'yes' | 'no' | ''

Match ───────────── { p1, p2, s1, s2, status, court }

AppState ────────── {
                      attendance: Record<string, AttendanceStatus>
                      memberLevels: Record<string, MemberLevel>
                      activityDate: string
                      courts: number
                      matches: Match[]
                      party: Record<string, PartyStatus>
                    }

GenerateOptions ─── {
                      pool: string[]
                      courts: number
                      matchType: MatchType
                      ruleEqual: boolean
                      ruleConsec: boolean
                      limitPer: number
                      limitTotal: number
                      isNoneMode: boolean
                    }

// フェーズ2 追加
User ────────────── {
                      name: string
                      uid: string
                      role_edit: boolean
                      role_admin: boolean
                      isFirstLogin: boolean
                    }
```
