```

│ 🏸 バドミントン試合管理    ● リアルタイム同期中 │
```

## S-03 出欠タブ

**目的:** 正規部員・ゲストが出欠を登録する

```
┌─────────────────────────────────┐
│ 活動日: 2026/05/10              │
│ リセット期限: 2026/05/17        │
│ ※活動日未設定の場合は未設定と表示│
│ [活動日を設定する] ← 変更全体権限│
├─────────────────────────────────┤
│  【正規部員】                    │
│  名前を選択: [▼ 選択してください] │
│  [参加] [不参加] [未定]          │
├─────────────────────────────────┤
│  【ゲスト】                      │
│  お名前: [入力欄]               │
│  [参加する]                     │
├─────────────────────────────────┤
│ 参加 (N人)  [一覧コピー]        │
│  ※参加者一覧は非表示（コピーのみ）│
├─────────────────────────────────┤
│ [出欠をリセット] ← 変更全体権限 │
└─────────────────────────────────┘
```

### 操作仕様

| 操作 | 動作 | 権限 |
|------|------|------|
| 正規部員：名前選択 → 参加/不参加/未定 | 出欠を登録・更新する | 変更（個人）以上 |
| ゲスト：名前入力 → 参加する | ゲストとして出欠登録する（参加のみ） | 全員 |
| 一覧コピー | 参加者の名前一覧をクリップボードにコピーする | 全員 |
| 活動日を設定する | 活動日設定モーダルを表示する | 変更（全体） |
| 出欠をリセット | 確認後、全出欠データをクリアする | 変更（全体） |

### M-01 活動日設定モーダル

```
┌─────────────────────────────┐
│ 活動日を設定                 │
│ パスワード: [__________]    │
│ 活動日: [date ピッカー]     │
│ [キャンセル] [設定する]      │
│ ※エラー時：「パスワードが違います」│
└─────────────────────────────┘
```

## S-04 メンバータブ

**目的:** 参加者のレベルとコート数を管理する

```
┌─────────────────────────────────┐
│ 参加者: N人  経験者: N人        │
│ 未経験者: N人  コート: N面      │
├─────────────────────────────────┤
│ コート数: [数値入力 1〜20]      │
│            ← 変更全体権限       │
├─────────────────────────────────┤
│ 名前          経験者/未経験者   │
│ 山田 太郎     [経験者  ▌]      │ ← トグル（変更全体権限）
│ 鈴木 花子     [未経験者]       │
│ ゲスト_田中   [未経験者]       │
│ ...                             │
└─────────────────────────────────┘
```

### 操作仕様

| 操作 | 動作 | 権限 |
|------|------|------|
| コート数入力 | コート数を直接数値入力で設定する（1〜20） | 変更（全体） |
| レベルトグル | 経験者 ↔ 未経験者を切り替える | 変更（全体） |

## S-05 組み合わせタブ

**目的:** 試合の組み合わせを生成・管理する

### レイアウト（生成前）

```
┌─────────────────────────────────┐
│ ── ルール設定 ────────────────── │
│ 参加枠: [全員] [経験者] [未経験] │
│ 形式:   [シングルス] [ダブルス]  │
│                                 │
│ 試合数（シングルス時）            │
│  ○ 1人あたり [__] 試合          │
│  ○ 合計試合数の上限 [__]        │
│  ○ 指定しない                   │
│                                 │
│ 試合数（ダブルス時）              │
│  ○ 合計試合数の上限 [__]        │
│  ○ 指定しない                   │
│                                 │
│ [▼ 均等にする（ON）]            │
│   全員の試合数を同じにする        │
│                                 │
│ [▼ 連続不可（ON）]              │
│   直前ラウンドの出場者は次に出ない│
├─────────────────────────────────┤
│ [組み合わせを生成]               │
└─────────────────────────────────┘
```

### レイアウト（生成後）

```
┌─────────────────────────────────┐
│ ▶ ルール設定（折りたたみ）       │
├─────────────────────────────────┤
│ 進捗: ████░░ 3/10試合完了       │
├─────────────────────────────────┤
│ ラウンド1                        │
│ ┌──────────────────────────────┐│
│ │コート1   山田 vs 鈴木         ││
│ │[待機中▼] [山田]: [  ] [鈴木]: [  ]││
│ └──────────────────────────────┘│
│ ┌──────────────────────────────┐│
│ │コート2   田中 vs 佐藤         ││
│ │[試合中▼]                    ││
│ └──────────────────────────────┘│
├─────────────────────────────────┤
│ [リセット] ← 変更全体権限        │
└─────────────────────────────────┘
```

### 操作仕様

| 操作 | 動作 | 権限 |
|------|------|------|
| 参加枠選択 | 全員・経験者のみ・未経験者のみ を切り替える | 変更（全体） |
| 試合形式選択 | シングルス / ダブルスを切り替える | 変更（全体） |
| 試合数設定 | 各種方式から選択・数値入力（最大99） | 変更（全体） |
| 均等にするトグル | ON/OFF を切り替える（初期値：ON） | 変更（全体） |
| 連続不可トグル | ON/OFF を切り替える（初期値：ON） | 変更（全体） |
| 組み合わせを生成 | アルゴリズムで試合一覧を生成しルール設定を折りたたむ | 変更（全体） |
| ステータス変更 | 待機中・試合中・終了 を切り替える | 変更（全体） |
| スコア入力 | 各試合の点数を入力する（0〜99） | 変更（全体） |
| リセット | 確認後、全試合データをクリアする | 変更（全体） |

### 表示ルール

| 条件 | 表示 |
|------|------|
| 均等にするON で均等にできない | 「均等にできません。よろしいですか？」警告を表示 |
| 参加者が試合形式に必要な人数未満 | エラーメッセージを表示し生成をブロック |
| 生成後 | ルール設定カードを自動折りたたみ（手動で開閉可能） |

## S-06 結果・順位タブ

**目的:** 試合結果と順位を確認する（閲覧専用）

```
┌─────────────────────────────────┐
│ 総試合: N件  完了: N件          │
│ 試合中: N件  残り: N件          │
│ 進捗: ████████░░ 80%            │
├─────────────────────────────────┤
│ 順位  名前         Pt 勝 負 分  │
│  🥇  山田 太郎 [経] 10  5  0  0 │
│  🥈  鈴木 花子 [経]  8  4  1  0 │
│  🥉  田中 一郎 [未]  6  3  2  0 │
│  4位  佐藤 次郎 [未]  4  2  3  0 │
│  ...                             │
└─────────────────────────────────┘
```

### 表示項目

| 項目 | 内容 | 計算方法 |
|------|------|---------|
| Pt | ポイント | 勝利+2pt・引き分け+1pt・敗北+0pt |
| 勝 / 負 / 分 | 勝敗数 | 完了した試合のみ集計 |
| メダル | 上位3名に🥇🥈🥉 | ポイント → 勝利数 → 得点差 で順位決定 |
| バッジ | [経] [未] | メンバーのレベルを表示 |

## S-07 懇親会タブ

**目的:** 懇親会の参加意向を確認する

```
┌─────────────────────────────────┐
│ 参加: N人  不参加: N人  未回答: N人│
├─────────────────────────────────┤
│ 【未回答（優先表示）】            │
│  山田 太郎  [参加する] [不参加]  │
│  鈴木 花子  [参加する] [不参加]  │
├─────────────────────────────────┤
│ 【回答済み】                     │
│  田中 一郎  ✅ 参加              │
│  佐藤 次郎  ❌ 不参加            │
├─────────────────────────────────┤
│ ※全員回答後：集計結果を表示      │
│  「参加 N人 / 不参加 N人」        │
├─────────────────────────────────┤
│ [リセット] ← 変更全体権限        │
└─────────────────────────────────┘
```

### 操作仕様

| 操作 | 動作 | 権限 |
|------|------|------|
| 参加する / 不参加 | 懇親会の参加意向を登録する | 参加者（正規部員）のみ |
| リセット | 確認後、全懇親会データをクリアする | 変更（全体） |

### 表示ルール

| 条件 | 表示 |
|------|------|
| 全員が回答済み | 集計結果「参加 N人 / 不参加 N人」を表示 |
| 未回答者あり | 未回答者を上部に優先表示する |

## S-08 ログイン画面（フェーズ2）

**目的:** 正規部員がランダムID とパスワードでログインする

```
┌─────────────────────────────────┐
│  🏸 バドミントン試合管理          │
│                                 │
│  ランダムID: [______________]   │
│  パスワード: [______________]   │
│                                 │
│  [ログイン]                     │
│                                 │
│  ─────────────────────────     │
│  [ゲストとして参加する]          │
└─────────────────────────────────┘
```

| 要素 | 内容 |
|------|------|
| ランダムID 入力 | 管理者から通知されたランダムIDを入力（@以降は不要） |
| パスワード入力 | 初回：共通パスワード `nicesoul`、2回目以降：変更後パスワード |
| ログインボタン | Firebase Authentication で認証する |
| ゲストとして参加 | ログインせず閲覧・懇親会登録のみ可能な状態で利用する |
