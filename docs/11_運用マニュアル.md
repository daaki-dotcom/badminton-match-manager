# 運用マニュアル

## バドミントン試合管理ツール

**バージョン:** 2.0  
**作成日:** 2026-05-07  
**対象:** 幹事（変更全体権限以上）・メンバー・開発者

---

## 第1章 アプリの基本操作

### 1-1. アプリの開き方

1. スマートフォンのブラウザ（Chrome または Safari）を開く
2. アプリの URL を入力する
3. 「接続中...」が表示されたあと、自動的にメイン画面に切り替わる

> **ヒント:** ホーム画面に追加するとショートカットとして使えます。  
> iPhone: Safari → 共有ボタン → ホーム画面に追加  
> Android: Chrome → メニュー（⋮）→ ホーム画面に追加

---

### 1-2. 画面の見方

```
┌──────────────────────────────────────┐
│ 🏸 バドミントン試合管理  ● 同期中    │ ← ヘッダー（常に表示）
│ 参加:8人  試合:10件  終了:6件       │
├──────┬───────┬──────┬───────┬──────┤
│ 📋   │ 👥    │ 🎯   │ 🏆    │ 🍻   │ ← タブ（タップで切替）
│ 出欠 │メンバー│組合せ│ 結果  │懇親会│
└──────┴───────┴──────┴───────┴──────┘
```

| 同期状態表示 | 意味 |
|------------|------|
| ● リアルタイム同期中 | 正常に Firebase と通信中 |
| 同期中... | データ書き込み処理中 |
| ⚠ 切断中 | インターネット接続が切れている |

## 第2章 活動当日の操作手順（幹事向け）

### STEP 1 — 活動日を設定する

1. **出欠タブ**を開く
2. 「活動日を設定する」をタップ
3. 管理者パスワードを入力する
4. 活動日を選択して「設定する」をタップ

> 活動日を設定すると、**7日後にゲストの出欠・懇親会データが自動削除**されます。  
> 正規部員の出欠データは削除されません。

---

### STEP 2 — 出欠を収集する

**正規部員の場合:**
1. 出欠タブを開く
2. リストから自分の名前を選ぶ
3. 「参加」「不参加」「未定」のいずれかをタップ

**ゲストの場合:**
1. 出欠タブを開く
2. 名前を自由入力する
3. 「参加する」をタップ（参加のみ登録可能）

> **注意（フェーズ1）:** 名前の表記を統一してください。  
> 「山田」と「山田太郎」は別人として扱われます。

---

### STEP 3 — メンバーのレベルとコート数を確認する

1. **メンバータブ**を開く
2. 参加者のレベル（経験者 / 未経験者）を確認・変更する
3. コート数を入力する（1〜20）

---

### STEP 4 — 試合の組み合わせを生成する

1. **組み合わせタブ**を開く
2. 参加枠を選ぶ（全員 / 経験者のみ / 未経験者のみ）
3. 試合形式を選ぶ（シングルス / ダブルス）
4. 試合数を設定する

   | 試合形式 | 選択肢 |
   |---------|--------|
   | シングルス | 1人あたり◯試合 / 合計試合数の上限 / 指定しない（総当たり） |
   | ダブルス | 合計試合数の上限 / 指定しない（フェーズ4完了まで） |

5. 均等にするトグル・連続不可トグルを必要に応じて設定する（初期値：両方 ON）
6. 「組み合わせを生成」をタップ

> 生成後、ルール設定が自動で折りたたまれます。タップで再度開けます。

---

### STEP 5 — 試合を進行する

1. 試合のステータスをタップで更新する
   - **待機中 → 試合中 → 終了** の順に変更する
2. 試合終了後にスコアを入力する（0〜99）
3. **結果・順位タブ**でリアルタイムに順位が確認できる

---

### STEP 6 — 懇親会の参加を確認する

1. **懇親会タブ**を開く
2. 各参加者が「参加する」「不参加」をタップして回答する
3. 全員が回答したら集計結果が表示される

---

## 第3章 よくある操作

### 試合をやり直したい

1. 組み合わせタブの「リセット」ボタンをタップ
2. 確認後、全試合データが削除される
3. 再度「組み合わせを生成」をタップ

### 出欠を修正したい

- **正規部員:** 出欠タブで自分の名前を再選択し、正しい出欠をタップ（上書き）
- **ゲスト:** 変更全体権限を持つ幹事が当該ゲストを削除し、再登録する

### ゲストが来られなくなった

1. 出欠タブを開く
2. 変更全体権限を持つ幹事が当該ゲストのエントリを削除する

### メンバーのレベルを変更したい

1. メンバータブを開く
2. 対象メンバーのトグルをタップ（経験者 ↔ 未経験者）

## 第4章 データのリセット仕様

| データ種別 | 自動リセット | 手動リセット | 備考 |
|-----------|------------|------------|------|
| ゲストの出欠 | 活動日から7日後 | 幹事が「出欠をリセット」 | 正規部員の出欠はリセットされない |
| 活動日 | 7日後にクリア | - | 設定のたびに上書き可能 |
| 懇親会 | 活動日から7日後 | 幹事が「リセット」 | |
| 試合データ | リセットしない | 幹事が「リセット」 | |
| メンバーレベル | リセットしない | 手動でトグル操作 | 永続保持 |
| コート数 | リセットしない | 数値入力で変更 | 永続保持 |

## 第5章 トラブルシューティング

| 症状 | 原因 | 対処 |
|------|------|------|
| 「接続中...」のまま動かない | インターネット接続なし / Firebase 障害 | 通信環境を確認する |
| 他の人の操作が反映されない | ブラウザのキャッシュ | ページを再読み込みする（F5 / スワイプ） |
| 組み合わせが生成されない | 参加者が不足（シングルス: 2人以上、ダブルス: 4人以上） | 参加者数を確認する |
| パスワードが通らない | パスワードが変更されている可能性 | 開発者に確認する |
| 画面がくずれる | 非対応ブラウザ | Chrome または Safari の最新版を使用する |

## 第6章 開発者向け — 環境構築・デプロイ

### 6-1. ローカル開発環境

**必要なもの:**
- Node.js 18 以上
- npm

```bash
# プロジェクトフォルダに移動
cd C:\Users\skgrk\Desktop\01_ClaudeCode\badminton-app

# 依存パッケージをインストール（初回のみ）
npm install

# 開発サーバー起動
npm run dev
```

ブラウザで `http://localhost:5173` を開くとアプリが表示されます。

---

### 6-2. ビルド

```bash
# TypeScript コンパイル + Vite ビルド
npm run build
```

`dist/` フォルダに本番用静的ファイルが生成されます。

---

### 6-3. GitHub Pages へのデプロイ

```bash
# 1. ビルドする
npm run build

# 2. dist/ の内容を gh-pages ブランチにプッシュする
#    （gh-pages パッケージを使う場合）
npm install --save-dev gh-pages

# package.json の scripts に以下を追加:
# "deploy": "gh-pages -d dist"

npm run deploy
```

**vite.config.ts の設定（GitHub Pages の場合）:**
```typescript
export default defineConfig({
  base: '/badminton-app/',  // リポジトリ名を指定
  plugins: [react()],
})
```

---

### 6-4. Firebase の設定変更

`src/firebase.ts` に Firebase プロジェクトの設定情報が記載されています。  
別の Firebase プロジェクトに変更する場合は、Firebase コンソールから設定情報を取得して置き換えてください。

> **セキュリティ:** Firebase API キーはクライアントに公開されますが、  
> Firebase コンソールで「承認済みドメイン」を設定することで不正利用を防止できます。

## 第7章 セキュリティ注意事項

| 項目 | 注意内容 |
|------|---------|
| アプリ URL | 不特定多数に公開せず、メンバー間のみで共有してください |
| 管理者パスワード | メンバーに教えないでください |
| 個人情報 | 氏名データは Firebase に保存されます。メンバーに同意を得てから使用してください |
| Firebase ルール | フェーズ1 は全読み書き許可状態です。フェーズ2 で認証連携ルールに変更してください |
