# 画面遷移図

## バドミントン試合管理ツール

**バージョン:** 2.0  
**作成日:** 2026-05-07

---

## 1. フェーズ1 全体遷移図（現行）

```
[アプリ起動]
    │
    ▼
[S-01 接続中画面] ── Firebase接続失敗 ──→ [エラー表示（再試行待ち）]
    │
    ▼ 接続成功
[S-02 メイン画面（タブバー）]
    │
    ├──────────────────────────────────────────────────────────────┐
    │                                                              │
    ▼                                                              │
[S-03 📋 出欠タブ]                                                 │
    │                                                              │
    ├─ 正規部員：名前選択 → 参加/不参加/未定 ボタン → 出欠更新       │
    ├─ ゲスト：名前入力 → 「参加」ボタン → 出欠登録                  │
    ├─ 「一覧コピー」ボタン → クリップボードにコピー                   │
    ├─ 活動日タップ（変更全体権限） → [M-01 活動日設定モーダル]       │
    │       └─ パスワード入力 → 日付選択 → 設定                     │
    └─ 「リセット」ボタン（変更全体権限） → 確認 → 出欠データクリア    │
                                                                  │
    ├──────────────────────────────────────────────────────────────┤
    │                                                              │
    ▼                                                              │
[S-04 👥 メンバータブ]                                              │
    │                                                              │
    ├─ コート数入力（変更全体権限） → コート数更新                    │
    └─ レベルトグル（変更全体権限） → 経験者/未経験者 切替            │
                                                                  │
    ├──────────────────────────────────────────────────────────────┤
    │                                                              │
    ▼                                                              │
[S-05 🎯 組み合わせタブ]                                            │
    │                                                              │
    ├─ 参加枠選択 → 全員/経験者のみ/未経験者のみ                     │
    ├─ 試合形式選択 → シングルス/ダブルス                             │
    ├─ 試合数設定 → 各種入力                                        │
    ├─ 均等にするトグル → ON/OFF                                    │
    ├─ 連続不可トグル → ON/OFF                                      │
    ├─ 「生成」ボタン（変更全体権限） → 試合一覧表示                  │
    │       └─ ルール設定カードが自動で折りたたまれる                  │
    ├─ ステータス変更（変更全体権限） → 待機中/試合中/終了            │
    ├─ スコア入力（変更全体権限） → 点数入力 → 更新                   │
    └─ 「リセット」ボタン（変更全体権限） → 確認 → 試合データクリア    │
                                                                  │
    ├──────────────────────────────────────────────────────────────┤
    │                                                              │
    ▼                                                              │
[S-06 🏆 結果・順位タブ]                                            │
    │                                                              │
    └─ 閲覧のみ（自動更新）                                         │
                                                                  │
    └──────────────────────────────────────────────────────────────┘
    │
    ▼
[S-07 🍻 懇親会タブ]
    │
    ├─ 「参加」/「不参加」ボタン（参加者のみ） → 回答更新
    └─ 「リセット」ボタン（変更全体権限） → 確認 → 回答クリア
```

## 2. フェーズ2 遷移図（ログイン実装後）

```
[アプリ起動]
    │
    ▼
[S-01 接続中画面]
    │
    ▼
[S-08 ログイン画面]
    │
    ├─ 正規部員：ランダムID + パスワード入力 → [Firebase Authentication]
    │       ├─ 初回ログイン → [S-09 パスワード変更強制画面]
    │       │       └─ 新パスワード設定 → [S-02 メイン画面]
    │       └─ 2回目以降 → [S-02 メイン画面（権限に応じた操作制限）]
    │
    └─ ゲスト：「ゲストとして参加」ボタン → [S-02 メイン画面（閲覧＋懇親会のみ）]

[S-02 メイン画面]
    │
    └─ 設定アイコン（管理者権限） → [S-10 アカウント管理画面]
            ├─ 正規部員追加 → ID発行・パスワード初期設定
            ├─ 権限付与 → 変更（全体）/ 登録 権限のON/OFF
            └─ 正規部員削除
```

## 3. モーダル一覧

| # | モーダル名 | 表示条件 | 権限 |
|---|-----------|---------|------|
| M-01 | 活動日設定モーダル | 活動日エリアタップ時 | 変更（全体） |
| M-02 | 出欠リセット確認 | リセットボタンタップ時 | 変更（全体） |
| M-03 | 試合リセット確認 | 組み合わせリセットボタンタップ時 | 変更（全体） |
| M-04 | 懇親会リセット確認 | 懇親会リセットボタンタップ時 | 変更（全体） |
| M-05 | パスワード変更（フェーズ2） | 設定メニューから | 正規部員 |
